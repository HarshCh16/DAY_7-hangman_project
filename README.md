# 🔤 Hangman Game (Python)

**Hangman** is a classic word-guessing game where one player thinks of a word, and the other tries to guess it by suggesting letters within a limited number of attempts. With each incorrect guess, a part of the "hangman" figure is drawn. The game ends when the word is guessed correctly or the figure is fully drawn.

This is a Python-based console version of Hangman where you guess a randomly chosen word one letter at a time before you run out of lives.


## 🧠 Core Concepts Used

This beginner-friendly program is built using basic Python features:

- `random.choice()` for word selection
- **Loops and conditionals** for game flow
- **String concatenation and indexing**
- **Lists/Sets** to track guessed letters
- **ASCII art** for visual representation
